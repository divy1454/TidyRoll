Tidyroll

Licences

Tidyroll runs entirely on your device. These are the open models, data and libraries it is built with.

MobileNetV2 image model
From the OpenCV Zoo. Apache License 2.0. Recognises scenes and objects (the 1000 ImageNet classes).
YuNet face detector
Copyright 2020 Shiqi Yu, via the OpenCV Zoo. MIT License. Finds faces; it does not recognise who people are.
ONNX Runtime Web
Copyright Microsoft Corporation. MIT License.
exifr
Copyright 2020 Mike Kovařík. MIT License. Reads photo dates and locations.
fflate
Copyright Arjun Barrett. MIT License. Makes ZIP downloads.
Country borders
Made with Natural Earth (public domain), packaged by world-atlas (ISC License).
Towns and time zones
Contains data from GeoNames, licensed under CC BY 4.0. Simplified to places with 5,000 or more people.
Sofia Sans and Sofia Sans Extra Condensed
Copyright 2019 The Sofia Sans Project Authors. SIL Open Font License 1.1.

The full licence texts ship with the source code in the licenses folder.
